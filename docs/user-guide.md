# Руководство пользователя

Откройте http://localhost:4200. Для входа можно использовать демонстрационные учётные записи
(список также есть на странице входа):

| Роль | Email | Пароль |
|------|-------|--------|
| Администратор | `admin@autoparts.local` | `Admin123!` |
| Менеджер | `manager@autoparts.local` | `Manager123!` |
| Покупатель | `customer@autoparts.local` | `Customer123!` |

## Покупатель

1. **Каталог.** Слева — фильтры: дерево категорий (выбор категории включает все её подкатегории), бренд,
   **подбор по автомобилю** (марка → модель), диапазон цены, «только в наличии». Сверху — строка поиска по названию,
   артикулу и OEM-номеру и сортировка. Параметры фильтров сохраняются в адресной строке, поэтому ссылкой на подборку
   можно поделиться.
2. **Карточка товара** содержит описание, артикул, OEM-номер, остаток и таблицу совместимых моделей автомобилей.
3. **Корзина.** Добавлять товары может только вошедший пользователь (гостя перенаправит на страницу входа).
   Нельзя положить больше, чем есть на складе; недоступные позиции подсвечиваются.
4. **Оформление заказа:** адрес доставки, телефон (белорусский номер, поле само подставляет +375 и формат `+375 (29) 123-45-67`), комментарий и способ оплаты (наличными или картой при получении,
   картой онлайн). Цены фиксируются в момент оформления, товар списывается со склада.
5. **Мои заказы** — история заказов со статусами. Пока заказ в статусе «Новый», его можно отменить.
6. **Профиль** — изменение имени, телефона и пароля.

Регистрация доступна на странице «Регистрация»; новый пользователь получает роль «Покупатель».

## Менеджер

Пункт меню **«Управление»**:

* **Панель** — количество товаров, товары с остатком меньше 5, заказы по статусам, выручка по доставленным заказам,
  число покупателей.
* **Товары** — поиск (в том числе по неактивным), создание и редактирование (бренд, категория, цена, остаток,
  совместимые модели), быстрое изменение остатка, деактивация (товар скрывается из каталога, но остаётся в истории заказов).
* **Категории, бренды, автомобили** — ведение справочников. Нельзя удалить категорию с подкатегориями или товарами,
  бренд с товарами, марку с моделями.
* **Заказы** — все заказы с фильтром по статусу и поиском по номеру (`AP-000012` или `12`) или email покупателя.
  Статус меняется только по допустимым переходам:
  «Новый» → «Подтверждён» → «Отправлен» → «Доставлен»; из «Нового» и «Подтверждённого» заказ можно отменить
  (товары вернутся на склад).

## Администратор

Всё, что доступно менеджеру, а также раздел **«Пользователи»**:

* поиск пользователей по email и имени, фильтр по роли;
* создание пользователя сразу с нужными ролями (например, нового менеджера);
* назначение ролей флажками — изменения вступают в силу сразу, без повторного входа пользователя;
* блокировка и разблокировка — заблокированный пользователь немедленно теряет доступ и не может войти.

Администратор не может снять роль «Администратор» с себя и заблокировать собственную учётную запись.
